## Shared Knowledge

The system follows Laravel conventions with multi-tenancy enforced through client_id scoping. All API endpoints require OAuth2 authentication via custom middleware. The FXConversionService provides currency conversion with 30-day lookback and commission calculation. The PocketExpenseCSVValidator handles batch validation with all-or-nothing approach - if any row fails, no expenses are created. User permission system uses delegation through user_feature_permission table where Primary Administrators can grant OOP expense management rights to other users. All models use soft delete patterns and follow Laravel naming conventions. The system integrates with existing Volopa infrastructure including file storage, queue system, and master data for currencies/countries.
