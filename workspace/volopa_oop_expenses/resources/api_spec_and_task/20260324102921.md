## Shared Knowledge

All models use Volopa legacy timestamp pattern with create_time and update_time DATETIME columns instead of Laravel's created_at/updated_at. Soft delete pattern uses deleted TINYINT(1) flag and delete_time DATETIME instead of Laravel's deleted_at. All controllers must use Oauth2UserClient middleware for authentication. Multi-tenant architecture requires client_id scoping on all queries. FXConversionService handles real-time currency conversion with 30-day lookback and commission calculations. CSV validation follows all-or-nothing principle - if any row fails validation, no expenses are created. ProcessExpenseUpload job runs on 'expense-processing' queue and processes uploads in batches of 100 records.
