## Shared Knowledge

Follow Laravel naming conventions: snake_case for tables/columns, PascalCase for models/controllers, camelCase for methods. Use DB transactions for multi-table operations. Implement eager loading to prevent N+1 queries. Cache reference data (currencies, expense types). Use UUID for upload tracking. OAuth2 middleware protects all endpoints with client data isolation.
