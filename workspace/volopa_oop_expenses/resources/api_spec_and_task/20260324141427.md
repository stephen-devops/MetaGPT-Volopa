## Shared Knowledge

All controllers use thin design pattern delegating to services. FXConversionService provides wallet currency integration with 30-day lookback. PocketExpenseCSVValidator performs atomic validation with preloaded reference data. All models use explicit Eloquent relationships with proper foreign key constraints. API Resources hide internal model fields and provide consistent response format. Queue jobs handle background processing for CSV imports. Policies enforce hierarchical RBAC based on user roles and delegation rights.

## Anything UNCLEAR

Several implementation details require clarification: (1) The specific notification channel for batch upload completion affects ProcessExpenseUpload job implementation. (2) Whether FX conversion reuses existing platform service infrastructure or requires new integration. (3) The exact audit logging mechanism for permission operations. (4) ClientFeatures model query pattern to check OOP feature enablement (feature_id = 16). (5) Table naming conventions showing both singular and plural forms. (6) Soft delete pattern preference between flag-based and Laravel SoftDeletes. These decisions may require platform architecture team input for consistency with existing Volopa infrastructure.
