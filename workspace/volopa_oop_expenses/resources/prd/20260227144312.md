## Programming Language

Laravel 10+ with PHP 8.2+

## Original Requirements

Build the Volopa OOP (Out-of-Pocket) Expenses API System using Laravel 10+ with PHP 8.2+. Three modules: 1. User Management & Permissions — RBAC via user_feature_permission with delegation hierarchy 2. Pocket Expense CSV Batch Upload — synchronous validation, async background sync 3. Single Expense Data Capturing — CRUD with FX conversion and flexible metadata

## Product Goals

- Enable comprehensive out-of-pocket expense tracking outside the Volopa card system
- Provide flexible permission delegation hierarchy for expense management
- Support efficient bulk expense entry via CSV batch upload
- Deliver automated FX conversion for multi-currency expenses
- Ensure secure API endpoints with proper authentication and authorization
- Maintain data integrity with atomic validation and transaction handling
- Provide extensible metadata capture for expense categorization
- Enable seamless integration with existing Volopa platform infrastructure

## User Stories

- As a Primary Administrator, I want to manage all users' expenses and delegate permissions so I can distribute workload effectively
- As an Administrator, I want to manage expenses for users delegated to me so I can handle approval workflows
- As a Business User, I want to create and manage my own out-of-pocket expenses so I can track personal business expenditures
- As a Card User, I want to record cash expenses alongside my card transactions so I have complete expense visibility
- As an Admin, I want to upload CSV files with bulk expenses for specific users so I can efficiently process historical data
- As a user, I want automatic FX conversion when entering expenses in different currencies so I don't need to calculate rates manually
- As a user, I want to categorize expenses with tracking codes and projects so I can organize expenses by business purpose
- As a user, I want to attach receipt files to expenses so I can maintain proper documentation
- As an Admin, I want detailed validation feedback for CSV uploads so I can correct data errors efficiently
- As a Primary Admin, I want to configure custom expense sources for my organization so users can select appropriate payment methods
- As a user, I want to view and edit draft expenses before submission so I can ensure accuracy
- As an approver, I want to approve or reject submitted expenses so I can maintain financial control

## Competitive Analysis

- Expensify: Strong mobile app, receipt scanning, but complex approval workflows
- Concur SAP: Enterprise-grade with deep ERP integration, but heavy UI and high learning curve
- Rydoo: European focus with good multi-currency support, but limited customization
- Zoho Expense: Affordable with basic features, but lacks advanced delegation capabilities
- Chrome River: Strong approval workflows, but outdated interface and limited API flexibility
- Receipts by Wave: Simple and free, but very basic feature set without delegation
- Abacus: Real-time expense tracking, but primarily US-focused with limited international features

## Requirement Analysis

The Volopa OOP Expenses system addresses a critical gap in expense management by handling out-of-pocket expenses that occur outside the card system. The three-module architecture provides comprehensive coverage: User Management establishes a flexible delegation hierarchy that scales from individual users to enterprise-wide administration; CSV Batch Upload enables operational efficiency for bulk historical data entry with robust validation; Single Expense Entry provides intuitive CRUD operations with automated FX conversion. The system leverages existing Volopa platform infrastructure (OAuth2, FX services, file storage) while introducing new capabilities like configurable expense sources and flexible metadata capture. Key technical requirements include atomic validation for CSV uploads, real-time FX conversion with user override capability, and a permission matrix that supports role-based access control with delegation. The system must handle multi-currency scenarios, maintain audit trails, and provide proper error handling with detailed feedback for validation failures.

## UI Design draft

RESTful API endpoints following Laravel conventions with versioned routes (/api/v1/). Authentication via OAuth2 middleware with proper JSON responses. Form validation using Laravel Request classes with detailed error messaging. Resource classes for consistent API response formatting. Database migrations with proper foreign keys and indexes. Policy classes for authorization checks. Service classes for business logic separation. Background job processing for async operations. File upload handling with storage integration.
