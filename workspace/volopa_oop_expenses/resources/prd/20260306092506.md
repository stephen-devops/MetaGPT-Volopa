## Programming Language

Laravel 10+, PHP 8.2+, MySQL

## Original Requirements

Build the Volopa OOP (Out-of-Pocket) Expenses API System using Laravel 10+ with PHP 8.2+. Three modules: 1. User Management & Permissions — RBAC via user_feature_permission with delegation hierarchy 2. Pocket Expense CSV Batch Upload — synchronous validation, async background sync 3. Single Expense Data Capturing — CRUD with FX conversion and flexible metadata

## Product Goals

- Enable comprehensive out-of-pocket expense tracking for employees outside the Volopa card system
- Implement flexible role-based permission delegation to reduce administrative bottlenecks
- Support efficient bulk expense entry through validated CSV batch uploads
- Provide automatic FX conversion with override capabilities for multi-currency expenses
- Ensure data integrity through atomic validation and transactional operations
- Deliver seamless integration with existing Volopa platform infrastructure
- Maintain secure access control with OAuth2 authentication and policy enforcement
- Support flexible metadata capture for categories, tracking codes, and projects

## User Stories

- As an employee, I want to create single out-of-pocket expense entries so I can track business expenses paid with personal funds
- As an employee, I want automatic FX conversion when entering expenses in different currencies so amounts are normalized to my wallet base currency
- As an employee, I want to override auto-converted amounts so I can correct for actual exchange rates used
- As an employee, I want to attach metadata like categories and tracking codes so expenses are properly classified
- As a Primary Administrator, I want to manage all user expenses by default so I can oversee organizational spending
- As a Primary Administrator, I want to delegate expense management rights to other users so I can distribute workload
- As an Administrator, I want to manage expenses for delegated users so I can handle approvals efficiently
- As an Administrator with management rights, I want to upload CSV batches for managed users so I can process bulk historical data
- As a user with CSV upload access, I want detailed validation errors with line numbers so I can fix and resubmit files
- As a user, I want to download a CSV template so I know the exact format required for batch uploads
- As a user, I want to configure custom expense sources for my client so I can categorize payment methods accurately
- As a user, I want to receive notifications when my batch upload completes so I know the status
- As a Primary Administrator, I want to revoke management rights so I can maintain proper access control
- As a user, I want my expenses to have different statuses (draft, submitted, approved, rejected) so approval workflows are tracked

## Competitive Analysis

- Expensify: Strong mobile app with receipt scanning, but limited role delegation and no CSV batch upload
- Concur SAP: Enterprise-grade with complex approval workflows, but heavyweight for mid-market clients
- Rydoo: Good FX conversion and multi-currency support, but lacks granular permission delegation
- Zoho Expense: Affordable with basic CSV import, but limited role-based access control
- Chrome River: Strong approval workflows and delegation, but poor user experience for bulk operations
- Webexpenses: Good CSV batch processing, but limited FX conversion capabilities
- Receipts by Wave: Simple expense tracking with basic CSV export, but no approval workflows

## Requirement Analysis

The Volopa OOP Expenses system addresses a critical gap in expense management for organizations using the Volopa platform. The system must integrate seamlessly with existing authentication, user management, and financial infrastructure while providing three distinct but interconnected modules. The User Management module establishes a sophisticated delegation hierarchy that goes beyond traditional RBAC, allowing Primary Administrators to grant granular permissions to any user regardless of role. The CSV Batch Upload module prioritizes data integrity through synchronous validation with detailed error reporting, followed by atomic batch creation. The Single Expense Entry module emphasizes user experience with real-time FX conversion, debounced API calls, and flexible metadata capture. Key technical challenges include maintaining referential integrity across normalized tables, implementing proper soft delete patterns, and ensuring transactional consistency during batch operations. The system must also handle multi-tenancy correctly, scope all data to appropriate clients, and maintain backwards compatibility with existing platform services.

## UI Design draft

The system is API-first with no direct UI components, designed to integrate with existing Volopa Web App interfaces. Single expense entry will extend the current expense management section with a form containing date picker, expense type dropdown, currency selector with auto-conversion display, merchant details fields, and metadata selection for categories/tracking/projects. CSV batch upload will add to the existing bulk operations section with user selection dropdown (for admins), template download link, file upload area with drag-and-drop, validation progress indicator, and error display table with downloadable CSV export. Permission management will integrate into the existing 'Settings > Manage Users' interface with additional toggles for OOP expense permissions per user. All interfaces will follow existing Volopa design patterns with consistent styling, responsive layouts, and accessibility standards.
