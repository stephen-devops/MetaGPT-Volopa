## Implementation approach

We will implement a Laravel 10+ RESTful API system following the Mental Model: Client → route (Oauth2UserClient middleware) → controller → FormRequest → service/model → API Resource → JSON. The architecture uses Controller-Service separation with thin controllers, comprehensive FormRequest validation, Policy-based authorization, and API Resources for all responses. For CSV upload, we implement synchronous all-or-nothing validation using PocketExpenseCSVValidator service with caching for reference data, followed by background job processing via Laravel Queues. The system uses DB transactions for data integrity, eager loading to prevent N+1 queries, and proper client_id scoping for multi-tenancy. FX conversion integrates with external APIs using debounced calls and 30-day rate lookback. All endpoints are protected by Oauth2UserClient middleware with user_feature_permission RBAC checks.

    participant R as Routes

    C->>R: POST /api/uploads/pocket-expense/csv
    R->>Mid: authenticate request
    Mid->>Ctrl: uploadCSV(request)
    Ctrl->>Req: validate form data
    Req->>Pol: authorize(user, clientId, targetUserId)
    Pol-->>Req: return authorization result
    Req-->>Ctrl: return validated data
    
    Ctrl->>DB: DB::transaction start
    Ctrl->>Svc: createUploadRecord(file, userId, clientId)
    Svc->>DB: PocketExpenseFileUpload::create()
    DB-->>Svc: return upload record
    
    Ctrl->>Val: new PocketExpenseCSVValidator(targetUserId, clientId)
    Val->>Val: cacheReferenceData()
    Ctrl->>Val: validate(csvFilePath)
    Val->>Val: parseCSV()
    Val->>Val: validateRow() for each row
    Val-->>Ctrl: return ValidationResult
    
    alt validation failed
        Ctrl->>Svc: updateUploadStatus('validation_failed', errors)
        Svc->>DB: update upload record
        Ctrl->>DB: DB::transaction rollback
        Ctrl->>Res: new ExpenseUploadResource(upload)
        Res-->>Ctrl: return error response
        Ctrl-->>C: 422 JSON with errors
    else validation passed
        Ctrl->>Svc: storeValidatedRows(validatedRows, uploadId)
        Svc->>DB: PocketExpenseUploadData::insert() bulk
        Svc->>DB: update upload record status='validation_passed'
        Ctrl->>DB: DB::transaction commit
        Ctrl->>Job: dispatch ProcessExpenseUpload(uploadId)
        Ctrl->>Res: new ExpenseUploadResource(upload)
        Res-->>Ctrl: return success response
        Ctrl-->>C: 201 JSON success
    end
    
    Job->>Svc: processUploadData(uploadId)
    Svc->>DB: get upload data in batches of 100
    loop for each batch
        Svc->>DB: DB::transaction start
        Svc->>Svc: createPocketExpenses(batchRows)
        Svc->>DB: PocketExpense::insert() bulk
        Svc->>DB: PocketExpenseMetadata::insert() bulk
        Svc->>DB: update upload_data status='synced'
        Svc->>DB: DB::transaction commit
    end
    Job->>Svc: updateUploadStatus('completed')
    Job->>Svc: sendCompletionNotification(targetUserId)
